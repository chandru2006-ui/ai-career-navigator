AI Career Navigator

An AI-powered Full Stack Web Application that evaluates technical skills, identifies individual skill gaps and generates personalized career roadmaps using Artificial Intelligence.

Project Overview

AI Career Navigator helps students and professionals understand their current skill level and provides structured learning paths based on AI analysis. The platform combines assessments, analytics and roadmap generation into one intelligent career guidance system.

Core Features

Skill Assessment

Evaluate programming and technical knowledge through AI-based assessments.

Gap Analysis

Identify missing skills required for selected career roles.

Career Roadmap

Generate personalized learning plans with milestones and timelines.

AI Mentor

Receive structured guidance, explanations and learning recommendations.
